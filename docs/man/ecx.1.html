NAME

ecx - command line for ecx

SYNOPSIS

ecx SUBCOMMAND [OPTION]...

DESCRIPTION

ecx is command line interface for computing electro-chemical properties:

EIS

Electrochemical Impedance Z=f(w)

Kinetics

j=f(U)

PEC

Iph=f(hv, U)

OPTIONS

all:

-u, --usage

Show usage text and exit.

-h, --help

Show help text and exit.

-V, --verbose

Display additional information when availabl

-v, --version

Show version information and exit.

EXAMPLES

Minimal example
ecx COMMAND [OPTION]...
